# Student Management System

A full-stack web application for managing student records, built with a modern tech stack. Admins can securely log in and perform full CRUD operations on student data.

## Tech Stack

**Frontend**
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Axios

**Backend**
- Spring Boot 4
- Spring Security (JWT Authentication)
- Spring Data MongoDB

**Database**
- MongoDB Atlas

## Features

- 🔐 Secure admin login with JWT authentication
- 👨‍🎓 Add, view, edit, delete, and search student records
- 📊 Dashboard overview
- 🔎 Real-time client-side search
- 🎨 Responsive UI with loading states
